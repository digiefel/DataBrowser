# Fonts

- `Lexend-Regular.ttf` and `Lexend-Bold.ttf`: Lexend, from revision
  [`7894f02`](https://github.com/googlefonts/lexend/tree/7894f02b2e7eabc48595f1d4eff3b17b48c6e651).
  Used for interface controls and labels.
  Distributed under the SIL Open Font License in `Lexend-LICENSE`.
- `JuliaMono-Regular.ttf` and `JuliaMono-Bold.ttf`: JuliaMono 0.63.2, from the
  [official release](https://github.com/cormullion/juliamono/releases/tag/v0.63.2).
  Used for code, printed values, and table content, including scientific symbols.
  Also supplies interface characters missing from Lexend.
  Distributed under the SIL Open Font License in `JuliaMono-LICENSE`.
- `lucide.ttf`: Lucide 1.52.0, used for browser icons.
  Distributed under the ISC license in `lucide-LICENSE`.
